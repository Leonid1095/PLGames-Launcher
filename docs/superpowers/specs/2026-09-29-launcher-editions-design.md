# Графические издания клиента в лаунчере — дизайн

Дата: 2026-09-29 · Статус: утверждён к разработке (разделы 2–5 — решения по умолчанию, открыты для правок)

## Цель

Сделать в лаунчере витрину «изданий» в духе World of Warcraft: Forever: игрок выбирает, как выглядит клиент 3.3.5a, а лаунчер ставит, включает и выключает нужные компоненты. Издания бесплатные и графические, без монетизации.

Попутно нужно починить установку клиента. Сейчас после торрента лаунчер записывает путём к игре папку с RAR и никогда его не распаковывает. В итоге новый игрок видит «wow.exe не найден».

## Решения, принятые с владельцем

| Вопрос | Решение |
|---|---|
| Что такое «издания» | Графические уровни клиента, бесплатно |
| Доставка | Гибрид. Тяжёлые HD-MPQ остаются в клиенте (текущий торрент), издание их только включает и выключает. Лёгкие слои (DXVK, ReShade, пресеты, в будущем DBC) качаются по манифесту с SHA-256 |
| Состав | Классика / Ремастер / Ультра плюс режим «Своё» |
| Хостинг манифеста и пакетов | Сначала `plgames-wow.ru`, при сбое GitHub Release (как у автообновления) |
| Погода | Отдельный серверный подпроект (`game_weather`), в этот дизайн не входит |
| Подход | Манифест компонентов, издания — пресеты, логика в отдельном модуле |
| База кода | Репозиторий PLGames-Launcher v0.3.4 плюс перенесённый деплой LiveCity |

## 1. Архитектура

- `content.py`: новый модуль без UI и без pywebview.
  - `ManifestClient` — загрузка, валидация и кэш манифеста.
  - `ComponentState` — `<игра>/PLGames/state.json`.
  - `Planner` — вычисляет разницу между текущим и целевым набором компонентов.
  - `Executor` — скачивание с проверкой SHA-256, атомарная раскладка файлов, откат при ошибке.
- `client_install.py`: новый модуль, распаковка RAR клиента (7-Zip → системный `tar` → ошибка с инструкцией) и поиск `wow.exe`.
- `app.py`: тонкие методы `Api` и страница «Издания». Переиспользуются `mpq_status`, `toggle_mpq`, `write_config_wtf` и `_safe_join`. Захардкоженный `hd_patches` становится компонентами манифеста, а локальная копия манифеста работает как запасной вариант без сети.

## 2. Манифест и хостинг

### Схема (`content-manifest.json`)

```json
{
  "schema": 1,
  "content_version": "2026.10.1",
  "project": "wow_chronos",
  "components": [
    {"id": "hd_textures", "name": "HD-текстуры", "group": "Графика", "type": "mpq",
     "files": [{"name": "patch-ruRU-4.MPQ", "folder": "Data/ruRU"},
               {"name": "patch-ruRU-5.MPQ", "folder": "Data/ruRU"}]},
    {"id": "dxvk", "name": "DXVK (Vulkan)", "group": "Производительность", "type": "files",
     "version": "2.4",
     "files": [{"path": "d3d9.dll", "size": 0, "sha256": "…",
                "urls": ["https://plgames-wow.ru/launcher/content/dxvk/2.4/d3d9.dll",
                         "https://github.com/Leonid1095/PLGames-Launcher/releases/download/content-2026.10.1/dxvk-2.4-d3d9.dll"]}],
     "conflicts": []},
    {"id": "ultra_config", "name": "Макс. дальность и эффекты", "group": "Настройки", "type": "config",
     "values": {"farclip": "1277", "spellEffectLevel": "6", "groundEffectDensity": "256"}}
  ],
  "editions": [
    {"id": "classic", "name": "Классика", "tagline": "Оригинальный Азерот 2008 года", "image": "…", "components": []},
    {"id": "remaster", "name": "Ремастер", "tagline": "HD-модели и текстуры", "image": "…", "components": ["hd_textures", "…", "dxvk"]},
    {"id": "ultra", "name": "Ультра", "tagline": "Новый свет и максимум деталей", "image": "…", "components": ["…", "reshade", "ultra_config"]}
  ],
  "table": [
    {"label": "HD-текстуры и модели", "components": ["hd_textures", "hd_models"]},
    {"label": "Новый свет (ReShade)", "components": ["reshade"]}
  ]
}
```

- Типы компонентов:
  - `mpq` включает или выключает файлы, которые уже есть в клиенте, переименованием `.disabled`;
  - `files` скачивает файлы и кладёт их в клиент;
  - `config` пишет значения в `WTF/Config.wtf`.
- Строка таблицы сравнения получает галочку у издания, если в издание входят все компоненты этой строки.
- **Безопасность путей.**
  - Любой путь из манифеста проходит через `_safe_join(game_dir, …)`.
  - Разрешены только расширения `.dll .ini .fx .fxh .png .dds .mpq .conf .txt .json`.
  - Перезапись `wow.exe` и файлов вне папки игры запрещена.
- Файл, скачанный с любого зеркала, принимается только при совпадении SHA-256 и размера.

### Хостинг

- Основной адрес: `https://plgames-wow.ru/launcher/content/manifest.json`, отдаётся nginx как статика. Настройку папки на сервере делает отдельная серверная задача.
- Резерв: GitHub Release `content-latest` в PLGames-Launcher с тем же `manifest.json` и файлами.
- Кэш: последний валидный манифест хранится в `%APPDATA%\PLGamesLauncher\content-manifest.json`. Без сети из него работают компоненты `mpq` и `config`, а `files` — только если уже скачаны.
- Публикация: `tools/build_content_manifest.py` собирает манифест из локальной папки `content/`, считает размеры и SHA-256 и выдаёт список файлов для загрузки на оба хостинга.

### Состояние (`<игра>/PLGames/state.json`)

```json
{"schema": 1, "edition": "ultra", "content_version": "2026.10.1",
 "components": {"dxvk": {"version": "2.4", "files": {"d3d9.dll": "<sha256>"}},
                "ultra_config": {"previous": {"farclip": "777"}}},
 "backups": {"d3d9.dll": "PLGames/backup/d3d9.dll"}}
```

- Если на месте нашего файла лежит чужой (хеш неизвестен), он сначала уходит в `PLGames/backup/`, а при удалении компонента возвращается.
- Для `config` запоминаются прежние значения, чтобы вернуть их при выключении.
- Для `mpq` источник правды — файловая система: суффикс `.disabled` и есть признак выключения.

## 3. Потоки

### Установка клиента

1. Торрент докачан. Автоматически идёт распаковка с прогрессом: байты на диске делятся на общий размер из листинга архива.
2. Перед распаковкой проверяется свободное место: размер распакованного плюс 1 ГБ.
3. После распаковки проверяется, что есть `…/PLGames_Wow3.3.5/wow.exe`, и путь к игре указывает на эту папку.
4. Игрок выбирает издание (первый запуск), затем «ИГРАТЬ».
5. Архив после распаковки сохраняется, если включена раздача. Иначе лаунчер предлагает удалить его и освободить 21 ГБ.
6. Кнопка «Распаковать архив…» есть и для случая, когда игрок скачал RAR сам.

### Первый запуск у игрока с уже установленным клиентом

- Если `state.json` нет, по состоянию MPQ определяется ближайшее издание. Если точного совпадения нет, ставится «Своё».
- На странице «Играть» показывается баннер «Выберите графическое издание».

### Применение издания

1. Если запущен `wow.exe`, применение отклоняется: «Закройте игру».
2. Planner считает действия: скачать, положить, убрать, включить или выключить MPQ, записать или вернуть значения конфига.
3. Все файлы скачиваются во временную папку `PLGames/tmp` с проверкой хешей. До этой точки клиент не менялся.
4. Действия применяются по журналу. При ошибке уже выполненные шаги откатываются в обратном порядке.
5. Записывается `state.json`.
6. Прогресс JS получает опросом `get_apply_status`, как у торрента.

### Warden

- Патчи `wow.exe` (дальность прорисовки, угол обзора, режим 4 ГБ) **не используются**: на проде 31 проверка памяти и действие «кик».
- DLL (ReShade, DXVK) и MPQ Warden не проверяет. Модульные проверки ловят только `RPE.DLL` и `WPESPY.DLL`, MPQ-проверок в `warden_checks` нет.

## 4. Интерфейс

- **Вкладка «ИЗДАНИЯ»** в верхнем меню, только для WoW-проекта.
  - Заголовок и подзаголовок.
  - Три карточки: картинка, название, слоган, кнопка «Выбрать», либо метка «Активно» у текущего издания.
  - Под карточками таблица сравнения с галочками, как у Forever. Используются тёмная тема и CSS-переменные лаунчера.
- **Рекомендация под ПК.** Видеокарта определяется через `Get-CimInstance Win32_VideoController`.
  - Встроенная Intel HD/UHD → «Классика».
  - Дискретная с 4 ГБ видеопамяти и больше → «Ультра».
  - Иначе → «Ремастер».
  - На рекомендованной карточке бейдж «Рекомендуем для вашего ПК».
- **«Своё»** — существующий блок HD-патчей в настройках, переведённый на компоненты манифеста. Любое ручное переключение делает активным издание «Своё».
- **Прогресс** — полоса и текст шага на странице изданий. На время применения кнопки заблокированы.
- **Мелкие правки по пути:**
  - `Api.window` переименовать в `_window`, чтобы pywebview не обходил `window.native` (шум в логе);
  - `FOLDER_DIALOG` заменить на `FileDialog.FOLDER`.

## 5. Контент, риски, тестирование

### Контент первой версии — что сделано (2026-09-29)

- **ReShade 6.8.0, обычная сборка.** Она подписана, но в онлайн-игре отключает буфер глубины (`runtime.cpp`, детектор сетевого трафика). Поэтому в пресет вошли только эффекты без глубины из набора prod80 (MIT): свечение, плёночная адаптация, цветовая температура, контраст/насыщенность, резкость. Компонент входит в «Ультра».
- **DXVK 3.1.1.** Требует свежий Vulkan, поэтому он только в «Своё» и конфликтует с ReShade.
- **Эксперимент «ReShade + DXVK» не проводился.** Выбран запасной вариант спецификации: они взаимоисключающие.
- **Файлы, которые программа переписывает сама**, помечены `mutable`.
- **Проверка без сервера:** `tools/try_content.py`.
- **Итог после проверки в игре (v0.4.0).**
  - Пресет prod80 владелец оценил как «выкручено, но слабо». «Ультра» перешла на ReShade с дополнениями: сетевой проверки там нет, глубина в онлайне работает.
  - Эффекты: Glamarye (затенение, FXAA, резкость, мягкий свет) и AdaptiveFog (туман). Для 3.3.5a нужен `DepthCopyBeforeClears=0`.
  - Контент публикуется в пререлизе GitHub `content-latest`, а сервер остаётся основным адресом, когда появится.

### Контент первой версии — исходный план

- **DXVK:** 32-битный `d3d9.dll` из официального релиза doitsujin/dxvk (лицензия zlib), плюс `dxvk.conf` с анизотропией 16x. WoW 3.3.5a — 32-битное приложение.
- **ReShade:** `d3d9.dll` (32-бит), минимальный набор шейдеров (затенение MXAO или SSAO, свечение, повышение резкости, тональная коррекция) и пресет `PLGames.ini`. Лицензии: ReShade — BSD-3, у шейдеров своя у каждого.
- **Небо и туман через `Light*.dbc`:** требует художественной настройки и откладывается на следующую итерацию. Схема манифеста это уже поддерживает: такой пакет будет компонентом `files` со своим MPQ.

### Риск: ReShade и DXVK одновременно

Обоим нужен `d3d9.dll`. Перед сборкой «Ультра» нужен отдельный эксперимент: ReShade как Vulkan-слой, зарегистрированный в HKCU без прав администратора, поверх DXVK. Если не получится, «Ультра» = ReShade без DXVK. В манифесте это выражается полем `conflicts`.

### Тестирование

- **`unittest` для `content.py`** на временных папках:
  - Planner (все переходы между изданиями);
  - проверка SHA-256 и размера, отказ при несовпадении;
  - откат при ошибке на середине;
  - безопасность путей (`..`, абсолютные пути, запрещённые расширения);
  - чтение и запись `state.json`;
  - бэкап и возврат чужого файла;
  - загрузка через локальный `http.server` в отдельном потоке.
- **`unittest` для `client_install.py`:** распаковка небольшого zip через тот же механизм (`tar`), поиск `wow.exe`, проверка свободного места, разбор прогресса.
- **Ручная проверка end-to-end:** лаунчер из исходников на фейковом клиенте (пустой `wow.exe` и MPQ-заглушки) и на реальном клиенте.
